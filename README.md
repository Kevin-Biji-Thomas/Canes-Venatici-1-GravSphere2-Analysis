# Canes-Venatici-1-GravSphere2-Analysis
Investigating the Core-Cusp Problem in Canes Venatici-1: A GravSphere 2 Analysis
The core-cusp problem is particularly challenging to investigate in faint dwarf spheroidal galaxies due to their limited kinematic data. Canes Venatici I is a faint dwarf spheroidal galaxy for which the available kinematic information is limited to line-of-sight velocities of 214 confirmed members, with no proper motion measurements. Therefore, we investigate the core-cusp problem in Canes Venatici I by applying GravSphere2, a higher-order Jeans modelling framework that uses individual kinematic measurements instead of radial binning. GravSphere2 had previously been applied only to mock data, but here, we apply it to the real dataset of CVn1. We test whether extracting more information through this method helps to distinguish between a core and a cusp at inner radii. At the innermost radius, the 95\% credible interval of the logarithmic slope encompasses both core and cusp-like values, while the 68\% credible interval lies between these two. These results indicate that for CVn1, the available kinematic data, even with the "bin-free" approach, do not provide sufficient information to distinguish between a core and a cusp in CVn1. This demonstrates that the limitations imposed due to a lack of sufficient data remain important even when using a framework that is designed to extract maximum information from kinematic measurements.
